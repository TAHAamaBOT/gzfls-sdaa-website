# 天文设备操作权限考核标准

:::info

本页公布本会天文设备操作权限的考核标准，依据[《设备管理办法（试行）》第六条](/docs/regulations/equipment-management-measures#chapter-2)制定并根据需要适时更新。

最后更新：2026年10月5日

:::

### C 级

**核心标准：能独立、规范、安全地使用手动目视设备系统**

- 能够识别望远镜系统的各个部件并了解其作用
- 能够独立完成目视望远镜系统组装、平衡、寻星镜校准和拆卸收纳
- 能够粗对极轴、对准目标、对焦，并将天体目标保持在视场内
- 掌握口径、焦距、焦比、放大率、视场等概念及其计算，能根据目标选择合适目镜
- 掌握防结露、防尘、镜片保护、安全搬运等设备常识
- 熟悉设备管理办法与安全规定

### B 级

**核心标准：能独立完成入门摄影设备、进阶目视设备的安装调试、观测运行、维护保养和常见异常处置。**

- 能够使用电动赤道仪、经纬仪的手控器，能够操作校准设置、GOTO与跟踪
- 能够搭建摄影系统，会安装天文相机、正确设置后截距，并正确连接滤镜轮、导星系统、电调焦等设备。
- 会使用极轴镜、天文盒子和漂移法精确对极轴；
- 能使用鱼骨板进行对焦，能使用电调焦精确对焦
- 能够使用导星系统，并能判断导星系统工作是否正常
- 熟悉天文盒子中各设备的参数调整与校准。
- 能够操作行星相机进行行星摄影
- 能够正确拍摄偏置、暗场、平场等校准场，并完成基础叠加处理。
- 会安全使用巴德膜、赫歇尔太阳滤镜等Ⅱ类太阳观测配件
- 能够熟练操作智能天文望远镜
- 能做好电源管理和线缆管理；
- 能处理软件死机、电源中断、线缆缠绕、视场污点、赤道仪异常停转等常见问题。

### A 级

**核心标准：能安全、规范、可靠地运行天文台主镜系统、日珥镜、大型双筒望远镜等高价值、高风险设备。**

- 熟悉协会所有设备的使用，能够使用 N.I.N.A. 操作天文台主镜摄影系统

- 能够对各类设备进行维护保养，包括防尘、防潮、防结露、防霉、安全搬运与存储
- 能做好电源管理、线缆管理
- 能及时发现并初步判断设备异常的性质和风险，能处理各类设备使用问题
