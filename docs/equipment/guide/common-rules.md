# 设备使用通用规则

无论使用什么设备，都请遵守以下几条规则。

:::danger

**不要直接用望远镜看太阳！** 太阳观测应当符合[《设备管理办法（试行）》第十六条](/docs/regulations/equipment-management-measures#第四章设备使用)的规定！

:::

- 观测前请取下设备的盖子，观测后请重新盖好
- 观测中不要转动固定部件用的紧锁旋钮或螺丝
- 在解开相应的紧锁螺丝或旋钮前，不要转动望远镜
- 松开锁紧旋钮前，先用手轻扶镜筒，避免镜子突然转动
- 镜片上有灰请用气吹处理，不要用衣服或者纸巾擦
- 不要用手触摸望远镜以及其他设备的镜片
- 不要在他人观测时遮挡视野或踢动望远镜脚架
- 不要握着望远镜的目镜端观测
- 零配件放载物盘上，不要乱丢
